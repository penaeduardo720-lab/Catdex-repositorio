# Política de Privacidad de [catdex]

Última actualización: Noviembre de 2026

Ed turner desarrollo catdex como una aplicación [gratuita / comercial]. Este servicio se proporciona tal cual.

## 1. Almacenamiento 100% Local
catdex está diseñada pensando en tu privacidad. **No contamos con servidores propios ni recopilamos, transmitimos o almacenamos tus datos personales o fotografías en la nube.** Toda la información generada en la aplicación se guarda exclusivamente de forma local en la memoria interna de tu dispositivo.

## 2. Permisos del Dispositivo
Para funcionar correctamente, la aplicación solicita acceso a los siguientes permisos, los cuales se procesan únicamente dentro de tu teléfono:
* **Cámara y Galería:** Se utilizan exclusivamente para capturar o seleccionar fotografías de gatos y guardarlas en tu colección local dentro de la app.
* **Ubicación (GPS):** Se utiliza únicamente en el momento en que registras un gato para guardar las coordenadas de avistamiento dentro de tu base de datos local y mostrarte tu mapa personal. Esta ubicación nunca se comparte con terceros.

## 3. Servicios de Terceros
Aunque la aplicación no envía tus fotos ni registros a internet, utiliza servicios estándar del sistema operativo para su distribución y funcionamiento básico:
* Google Play Services / Apple App Store

## 4. Control y Eliminación de Datos
Tú tienes el control total de tu información. Puedes borrar registros individuales desde la aplicación, o eliminar todos los datos de forma permanente borrando el almacenamiento de la app en los ajustes de tu teléfono o desinstalándola.

## 5. Privacidad de los Menores
Esta aplicación no recopila información personal de ningún usuario, incluidos menores de 13 años.
